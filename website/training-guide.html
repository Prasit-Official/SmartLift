เรียนรู้ท่าทาง
แล้วฝึกอย่างเข้าใจ

เรียนหลักการยกและการยืน ทำแบบทดสอบก่อน–หลังเรียน แล้วฝึกผ่านโปรแกรม Python ซึ่งสังเกตมุมลำตัวและข้อต่อ พร้อมแสดงข้อจำกัดของผลประเมิน

SYSTEM READYPOSE MONITOR
ลำดับขั้นตอน

หลักการยกของอย่างถูกยศาสตร์ 5 ขั้น

พิจารณางาน สิ่งของ และพื้นที่ร่วมกับท่าทาง หลักการต่อไปนี้อ้างอิงแนวทาง HSE; ค่ามุมในโปรแกรมเป็นค่าทดลองที่ต้องตรวจสอบเพิ่มเติม

01

ยืนให้มั่นคง

เตรียมพื้นที่และตำแหน่งเท้าให้มั่นคง เว้นพื้นที่ให้ขยับเท้าได้ และพิจารณาว่าต้องใช้ความช่วยเหลือหรืออุปกรณ์หรือไม่

งอสะโพกและเข่าอย่างเหมาะสม

HSE แนะนำการงอหลัง สะโพก และเข่าเล็กน้อยตอนเริ่มยก ไม่จำเป็นต้องย่อลึกสุด และไม่ควรเพิ่มการก้มหลังระหว่างยก

03

จับให้แน่น ของชิดตัว

กระชับมือให้มั่น ให้สิ่งของอยู่ใกล้ลำตัวที่สุด ยิ่งของห่างตัวมาก แรงกดหลังยิ่งเพิ่มเป็นทวีคูณ

04

เคลื่อนไหวอย่างราบรื่น

เคลื่อนไหวอย่างราบรื่น หลีกเลี่ยงการกระชาก และพิจารณาการเคลื่อนไหวของลำตัวกับขาร่วมกัน

05

ขยับเท้าเพื่อเปลี่ยนทิศทาง

เปลี่ยนทิศทางด้วยการขยับเท้าหมุนตัวทั้งตัว หลีกเลี่ยงการบิดหมุนที่เอวขณะแบกน้ำหนัก

ทบทวนความเข้าใจ

แบบทดสอบก่อน–หลังเรียน

ทำก่อนอ่านบทเรียนหนึ่งครั้ง แล้วทบทวนอีกครั้งหลังเรียน คะแนนนี้เป็นคะแนนความรู้ แยกจากผลฝึกด้วยกล้อง

ผลเก็บเฉพาะในหน้านี้ หากปิดหรือรีเฟรชจะหาย กรุณาดาวน์โหลดก่อนปิด และใช้รหัสเดียวกับโปรแกรมฝึก

การยืนทำงาน

เปลี่ยนอิริยาบถและจัดพื้นที่ให้เหมาะกับงาน

CCOHS แนะนำให้เปลี่ยนท่าทางเป็นระยะ มีโอกาสพัก และจัดความสูงกับระยะเอื้อมของงานให้เหมาะสม โปรแกรมต้นแบบสังเกตการเปลี่ยนมุมในภาพได้ แต่ไม่วัดแรงกดเท้าหรือยืนยันความสมดุลของร่างกาย

ภาคปฏิบัติ

เริ่มฝึกด้วยโปรแกรม LiftSaveWithAi

ใช้โปรแกรม Python จากชุดโปรเจกต์ การประเมินทั้งหมดอยู่ในโปรแกรมและบันทึกผลไว้ในเครื่อง

1. เตรียมระบบ

ติดตั้งตาม README_TH.md และวางไฟล์ yolo11n-pose.pt ในโฟลเดอร์ models กล้องควรอยู่แนวระดับและเห็นผู้ฝึกจากด้านข้างเพียงหนึ่งคน ตั้งแต่ไหล่ถึงข้อเท้า

2. เริ่มสังเกตท่าทาง

ใช้กล่องเปล่าสำหรับการสาธิตภายใต้การดูแลของผู้สอน เปิดโปรแกรม เลือกโหมด lifting หรือ standing แล้วกด Space เมื่อจัดกล้องเรียบร้อย โปรแกรมไม่ตรวจยืนยันมุมกล้องอัตโนมัติ

3. อ่านผลตามขอบเขต

OBSERVED = ไม่พบธงเตือนจากกฎทดลอง, REVIEW = ควรทบทวน, UNKNOWN = ข้อมูลไม่พอ, INCOMPLETE = รอบฝึกไม่ครบ ไม่ใช้ผลเหล่านี้ยืนยันความปลอดภัยทั้งหมด

คำสั่งเริ่มฝึก: python app.py --mode lifting --subject P001

กด Space เพื่อเริ่ม/พัก, R เพื่อตั้งต้นใหม่, Esc เพื่อจบและบันทึกผล โปรแกรมจะแสดงตำแหน่งรายงานหลังจบ

ไม่บันทึกวิดีโอโดยค่าเริ่มต้น รายงานมีรหัสผู้ฝึก มุมที่วัดได้ และผลรายรอบ การย่อแล้วยืนจะถูกเรียกว่า “รอบฝึกท่าทาง” เพราะยังไม่มีการตรวจวัตถุ

ระวังไว้

ข้อผิดพลาดที่พบบ่อยที่สุด

ประเด็นต่อไปนี้ควรพิจารณาร่วมกับน้ำหนัก ลักษณะงาน และสภาพแวดล้อม

ก้มหลังโค้งแทนการย่อเข่า

สังเกตการเคลื่อนไหวของลำตัวร่วมกับสะโพกและเข่า มุมเอียงลำตัวจากกล้องไม่ใช่ค่าความโค้งของกระดูกสันหลัง

ยกของไกลจากลำตัว

ยิ่งของอยู่ห่างจุดหมุนสะโพก แรงบิดที่หลังต้องรับยิ่งมากขึ้นตามระยะทาง แม้น้ำหนักของจะเท่าเดิม

บิดเอวขณะยกหรือถือของ

HSE แนะนำให้ขยับเท้าเพื่อเปลี่ยนทิศทางแทนการบิดลำตัวขณะยก โปรแกรมกล้องด้านข้างชุดนี้ยังประเมินการบิดไม่ได้

แหล่งอ้างอิง

อ่านเพิ่มเติม

  • HSE: Good handling technique
  • NIOSH: Revised NIOSH Lifting Equation — ระบบนี้ยังไม่คำนวณ RNLE
  • CCOHS: Working in a Standing Position
  • เอกสารรายวิชา “ท่าทางการทำงานหน่วยที่ทำงาน” หน้า 17 และ 65
  • วิดีโอที่ผู้จัดทำระบุ — ยังไม่ได้ตรวจเนื้อหา จึงยังไม่ใช้กำหนดเกณฑ์
