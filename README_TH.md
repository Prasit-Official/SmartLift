# LiftSaveWithAi — รุ่นต้นแบบ 0.2.0

เว็บไซต์บทเรียน + โปรแกรม Python สังเกตท่าทางการยก/การยืน
ค่ามุมใน criteria.json เป็นค่าทดลอง ไม่ใช่เกณฑ์ที่แหล่งอ้างอิงรับรอง
ผล OBSERVED ไม่เท่ากับปลอดภัยหรือผ่านการรับรองจากผู้เชี่ยวชาญ

## 1. ติดตั้ง (แนะนำ Python 3.11 แบบ 64-bit)
เปิด Terminal ในโฟลเดอร์โปรเจกต์ บน Windows:

```bat
py -3.11 -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
```

macOS/Linux ใช้ `python3 -m venv .venv` แล้ว `source .venv/bin/activate`
ยังไม่ได้ทดสอบติดตั้งบนทุก OS; เวอร์ชันที่ระบุเป็นช่วงใช้งาน ให้บันทึกเวอร์ชันที่ทดสอบบนเครื่องจริงด้วย `python -m pip freeze > requirements-lock.txt`

## 2. เตรียมโมเดล
ไฟล์น้ำหนัก YOLO และชุดข้อมูลฝึกไม่ได้แนบมา จึงไม่รวมไว้ในชุดโค้ดนี้
ถ้ามีไฟล์เดิม ให้คัดลอก `yolo11n-pose.pt` ไปที่ `models/`
หรือดาวน์โหลดจาก Ultralytics ในสภาพแวดล้อมที่เชื่อมอินเทอร์เน็ต:

```bat
python -c "from ultralytics import YOLO; YOLO('yolo11n-pose.pt')"
```

ย้ายไฟล์ที่ดาวน์โหลดไป `models/yolo11n-pose.pt`
อ้างอิง https://docs.ultralytics.com/models/yolo11/
รุ่นนี้โหลดไฟล์ท้องถิ่นและแจ้งข้อผิดพลาดหากไม่มีไฟล์ ไม่ดาวน์โหลดระหว่างเริ่มฝึก

## 3. เปิดบทเรียน
เปิด `website/lift-safe-training.html` ด้วยเบราว์เซอร์
ทำแบบทดสอบก่อนเรียน อ่านบทเรียน แล้วเลือกหลังเรียนและตอบอีกครั้ง
กดดาวน์โหลดผล JSON ก่อนปิดหน้าเว็บ; ใช้รหัสผู้ฝึกเดียวกับโปรแกรม
เว็บไม่มีการเปิดกล้องและไม่ส่งผลไปเซิร์ฟเวอร์ คะแนนเว็บกับผลโปรแกรมแยกไฟล์กันในรุ่นนี้

## 4. เปิดโปรแกรมฝึก

```bat
python app.py --mode lifting --subject P001
python app.py --mode standing --subject P001
```

ตัวเลือก:
- `--source 1` เปลี่ยนกล้อง / `--source path/to/video.mp4` ทดสอบด้วยวิดีโอ
- `--side left` หรือ `right` ล็อกด้านร่างกาย; ค่าเริ่มต้น auto เลือกครั้งแรกแล้วล็อกจน reset
- `--device cpu` ค่าเริ่มต้น; `--device 0` สำหรับ CUDA ที่ตั้งค่าแล้ว
- `--output reports` เปลี่ยนที่เก็บผล
- `--model path/to/yolo11n-pose.pt` ระบุโมเดล

กล้องต้องอยู่แนวระดับ เห็นผู้ฝึกจากด้านข้างเพียงหนึ่งคนและเห็นไหล่ถึงข้อเท้าครบ
เลือกพื้นที่โล่ง ใช้กล่องเปล่าสำหรับสาธิตภายใต้การดูแลของผู้สอน
โปรแกรมไม่สามารถยืนยันมุมกล้องหรือความปลอดภัยทั้งหมดอัตโนมัติ
กด **Space** เพื่อยืนยันการจัดกล้องและเริ่ม/พัก, **R** เพื่อตั้งต้นใหม่, **Esc** เพื่อจบ
การพัก/ตั้งต้นใหม่ยุติรอบค้างเป็น INCOMPLETE; จำนวนรอบสะสมยังอยู่ในรายงาน
หน้าจอฝึกเป็นภาษาไทยผ่าน Pillow โดยเลือกฟอนต์ Tahoma/Leelawadee บน Windows อัตโนมัติ หากไม่พบฟอนต์ให้ตั้ง LIFTSAVE_THAI_FONT เป็นที่อยู่ไฟล์ .ttf ภาษาไทย

## 5. ความหมายผล
- READY: รอเริ่ม/จัดกล้อง
- OBSERVED: ไม่พบธงเตือนจากกฎทดลองที่วัดได้ ไม่ใช่ผลปลอดภัย
- REVIEW: ค่าที่วัดเข้าเงื่อนไขทบทวนของต้นแบบ
- UNKNOWN: ข้อมูลไม่พอหรือมีจำนวนคนไม่ตรงเงื่อนไข
- REMINDER: มุมที่สังเกตเปลี่ยนน้อยตามเวลาสาธิตในโหมดยืน
- INCOMPLETE: รอบฝึกไม่ครบ มีข้อมูลขาดช่วง หรือผู้ใช้ยุติระหว่างรอบ

รอบฝึก: WAIT_READY -> READY -> DESCENDING -> LOWERED -> RISING -> จบรอบ
ต้องยืนตั้งต้นก่อน หากเริ่มจากท่าย่อจะยังไม่นับรอบ
การย่อ/ยืนโดยไม่มีของก็เป็นรอบฝึกได้; ยังไม่เรียกว่า AI ยืนยันการยกวัตถุ
ข้อมูลข้อมือที่ขาดไม่ถูกแทนค่า และไม่ใช้ระยะมือยืนยันระยะสิ่งของ
ไม่มีการตรวจความโค้งกระดูกสันหลัง การบิดสามมิติ แรงกล้ามเนื้อ น้ำหนัก หรือคุณภาพการจับ

## 6. รายงานและข้อมูลฝึก
ค่าเริ่มต้นเก็บที่ `~/LiftSaveWithAiData/reports/<session>/` หรือกำหนด `LIFTSAVE_DATA_DIR`
- `features.csv`: ข้อมูลดิบสูงสุด 10 ตัวอย่าง/วินาที รวมสถานะและช่อง label ว่าง
- `cycles.csv`: ผลรายรอบ
- `summary.json`: เกณฑ์ที่ใช้ ผลรายรอบ และจำนวนตัวอย่างแต่ละสถานะ
ไม่บันทึกภาพ/วิดีโอโดยค่าเริ่มต้น
UNKNOWN เป็นผลที่ต้องรายงาน ไม่ควรลบทิ้งจากรายงานเพื่อเพิ่มความแม่นยำ

สำหรับฝึก classifier: รวม CSV และเลือกแถวข้อมูลครบ โหมด lifting แล้วให้ผู้ประเมินติด label จาก rubric ที่ตรวจรับรอง
ใช้ subject_id จริงแบบรหัส เช่น P001 และคนเดิมต้องใช้รหัสเดิมทุก session
อย่าสร้าง label จาก rule_status อัตโนมัติแล้วใช้คะแนนโมเดลยืนยันกฎเดิม
สคริปต์ต้องมีอย่างน้อย 5 คนและอย่างน้อย 2 คลาสที่มี coverage ในแต่ละ fold; นี่เป็นข้อกำหนดเทคนิคขั้นต่ำ ไม่ใช่จำนวนข้อมูลที่รับรองความน่าเชื่อถือ

```bat
python -m pip install -r requirements-training.txt
python train_classifier.py --csv dataset/labelled.csv
python app.py --subject P001 --classifier models/lifting_classifier.pkl
```

ตัวจำแนกเป็นข้อมูลทดลองเพิ่มเติม ไม่แทนกฎและไม่เปลี่ยนผลรอบอัตโนมัติ
ใช้โมเดล .pkl ที่ฝึกเองหรือเชื่อถือได้เท่านั้น
Metrics แยกผู้ฝึกและวัดระดับแถว/เฟรม ยังต้องตรวจระดับรอบกับผู้ประเมินต่างหาก
